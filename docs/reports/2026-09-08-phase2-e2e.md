## 各腿结果（全部真实输出摘录）

### 1. baidu Z: 上传/下载往返 ✅
- 5MiB 随机 + 10B 小文件 `cp` 到 Z:（Explorer 等价链路：MiniRedir PUT→队列→transport 三步曲）；`cydrive status` = running；远端 list：`_e2e_b1_roundtrip5m.bin s=5242880`、`_e2e_small.txt s=10`（尺寸精确）
- `cache clear` 后 Z: 读回：`cmp` **逐字节相等**（ROUNDTRIP BYTE-EQUAL）

### 2. Range 播放（媒体拖播语义）✅
- `curl -r 1000000-1000999` 直打 WebDAV 8391 → 与源文件同窗口 `dd` 切片 `cmp` **逐字节相等**（RANGE-1K-BYTE-EQUAL；驱动 4MiB 有界分片拼接对上层透明）

### 3. 断点续传中途杀进程恢复 ✅（K7 真机复刻 spike §3 场景）
- 200MB PUT 过程中 `taskkill /F`：会话文件捕获于 `%TEMP%\cloudfs-e2e\b1\baidu_state\...`（50/50 分片 done、仅缺 create 收尾——上传队列入队即传 + 逐片落盘生命周期的直接证据）
- 重启实例：log 含 `requeue`/`resume`；**0 分片重传 + create 收尾** → 远端 `_e2e_resume200m.bin s=209715200` 完整落地；会话文件清零（成功即作废）
- 过程副产物：40MB 文件在 4 并发整文件路径下 ~6s 内传完（kill 前已完成）——transport 面 4 并发吞吐远超 stager 串行路径的又一实证

### 4. 删除语义（K4 remote-delete 真机）✅
- `rm /z/_e2e_small.txt` → 4s 后远端 list **该文件消失**（先删远端再删行的接线真机生效；云端无孤儿）

### 5. local V: 挂载/写读删 ✅

### 6. 双盘并存互不干扰 ✅
